# DeployLab

Учебный пет-проект: платформа, которая в следующих этапах будет получать исходный код приложения, собирать Docker-образ и помогать запускать приложение.

## Этап 1: минимальный веб-сервис

Сейчас в проекте есть два HTTP-адреса:

- `/` — приветствие и имя платформы;
- `/health` — простой сигнал, что процесс приложения отвечает.

### Запуск на Windows

Из папки `DeployLab` выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000/>. Интерактивная документация API находится на <http://127.0.0.1:8000/docs>.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Учебный маршрут

1. Минимальный веб-сервис и HTTP API.
2. Git и командная работа через ветки и pull request.
3. Linux-процессы, права, systemd, логи и сеть.
4. Bash-скрипты с безопасным режимом ошибок.
5. Dockerfile и локальный запуск через Compose.
6. CI: автоматическая сборка и проверки.
7. Kubernetes: Pod, Deployment, Service, ConfigMap и отладка.
8. Облачная виртуальная машина, сеть и базовый IAM.

Каждый этап будем разбирать: что делаем, зачем это платформе и как проверить результат.
