# DeployLab

Учебный пет-проект: платформа, которая постепенно научится получать исходный код приложения, собирать Docker-образ и помогать запускать приложение.

Сервис пишем на Node.js. На первом этапе используем встроенный модуль `node:http`, без внешних библиотек: так можно увидеть, как HTTP-сервер принимает запрос и формирует ответ.

## Этап 1: минимальный веб-сервис

- `GET /` — имя платформы и приветствие;
- `GET /health` — сигнал, что процесс отвечает;
- любой другой адрес — ответ `404 Not found`.

### Запуск

Из папки проекта выполните:

```powershell
npm start
```

Откройте `http://localhost:3000/` или `http://localhost:3000/health`. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

Порт можно изменить через переменную окружения `PORT`:

```powershell
$env:PORT = "4000"
npm start
```

## Что происходит в коде

1. `createServer(...)` создаёт HTTP-сервер и передаёт нашей функции каждый входящий запрос.
2. В объекте `request` читаем HTTP-метод и путь, например `GET` и `/health`.
3. `writeHead(...)` задаёт статус и заголовки ответа.
4. `end(...)` отправляет тело ответа и завершает запрос.
5. `listen(...)` начинает слушать порт. `0.0.0.0` позволяет позднее обращаться к сервису из контейнера или другой машины, а не только через loopback-интерфейс.

## Учебный маршрут

1. HTTP-сервис на Node.js и основы запросов и ответов.
2. Git: ветки, pull request и разрешение конфликтов.
3. Linux: процессы, права, systemd, логи и сеть.
4. Bash-скрипты с `set -euo pipefail`.
5. Dockerfile и локальный запуск через Compose.
6. CI: автоматическая сборка и проверки.
7. Kubernetes: Pod, Deployment, Service, ConfigMap и отладка.
8. Облачная виртуальная машина, сеть и базовый IAM.

На каждом этапе разбираем, что делаем, зачем это нужно платформе и как проверить результат.
