# DeployLab

Учебный пет-проект: платформа, которая постепенно научится получать исходный код приложения, собирать Docker-образ и помогать запускать приложение.

Сервис пишем на Node.js. На первом этапе используем встроенный модуль `node:http`, без внешних библиотек: так можно увидеть, как HTTP-сервер принимает запрос и формирует ответ.

## Этап 1: минимальный веб-сервис

- `GET /` — имя платформы и приветствие;
- `GET /health` — сигнал, что процесс отвечает;
- любой другой адрес — ответ `404 Not found`.

### Запуск

Из папки проекта выполните:

```powershell
npm start
```

Откройте `http://localhost:3000/` или `http://localhost:3000/health`. 

Порт можно изменить через переменную окружения `PORT`:

```powershell
$env:PORT = "4000"
npm start
```
